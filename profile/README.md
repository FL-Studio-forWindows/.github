- Develop detailed music production projects using familiar desktop workflows.

## 🚀 Key Features

- **Piano Roll** — Edit notes, velocities, pitch and timing with detailed MIDI control.
- **Channel Rack** — Build step patterns and organize instruments within channel groups.
- **Playlist Arrangement** — Place patterns, audio clips and automation across the song timeline.
- **Mixer Routing** — Shape signal flow using mixer inserts, sends, buses and effects.
- **Plugin Instruments** — Create sound with built-in and compatible third-party instruments.
- **Audio Recording** — Capture live performances and organize recordings as editable clips.
